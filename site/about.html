systemcards.org is a public index of AI model documentation: model cards, system cards, and independent evaluation reports.

What it does

  • Catalogs documents from an allowlist of AI labs and independent evaluators.
  • Links originals. Never re-hosts them.
  • Fingerprints every document daily. Silent edits become recorded versions.
  • Shows provenance for every entry: when, how, and why it was added.

How it works

  • A deterministic monitor checks every link daily, re-fetches a rotating subset, and diffs publisher index pages for new documents.
  • An LLM agent triages candidates and proposes entries. A deterministic validator (allowlist, fetchability, dedup, caps) has the final say on every write.
  • The database is public SQLite in the GitHub repo; this site is a static export of it.

Corrections

  • Wrong entry: use the "report an issue" link on its page.
  • Missing document: file an issue.
