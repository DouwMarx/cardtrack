1       Introduction

Today, we’re introducing an update to GPT-6 Luna, which we released in ChatGPT on October
7. The updated model provides more concise responses and reduces overly agreeable language.
We refer to the updated model as GPT-6 Luna (October 29) throughout the remainder of this
system card.

Under our Preparedness Framework, we are treating GPT-6 Luna (October 29) as High in
cybersecurity and High for Biological and Chemical capability. Based on that assessment, GPT-6
Luna (October 29) uses the same safeguards stack as prior GPT-6 Luna (October 7), described
in detail in the GPT-6 Luna (October 7) card.

2       Model Data and Training

GPT-6 Luna (October 29) uses the same types of data and training as GPT-6 Luna (October 7),
described in the GPT-6 Luna (October 7) card.

For previously launched models, the values published at launch reflect the versions evaluated at
that time. The comparison values for previously launched models that are shown here may reflect
later versions of those models, and may vary from the values published at launch.1

For a full description of the evaluations in this section, please see the Model Safety section in the

4.2   Prompt Injection

GPT-6 Luna (October 29) is highly robust to prompt injection. We have continued to scale our
GPT-Red approach, where we use adversarial training with an automated red-teaming agent to
strengthen resistance to malicious instructions while preserving the ability to complete legitimate
tasks.

For our evaluations, we use the GPT-Red automated evaluations introduced in the GPT-5.6
system card. These cover both "direct" prompt injection attacks (or “instruction hierarchy”
violations), where a user attempts to override higher-priority system or developer instructions,
and "indirect" attacks, where malicious instructions in third-party content attempt to redirect an
agent beyond the user’s request.

GPT-6 Luna (October 29) saturates instruction hierarchy evaluations, achieving 99.91% robust-
ness.

8.1.2     Cybersecurity Capabilities

8.1.2.1    ExploitBench

ExploitBench evaluates model ability to turn known vulnerabilities into increasingly powerful
exploit primitives, up to arbitrary code execution, using vulnerability descriptions, source code,
and patches without a reference exploit. At maximum reasoning effort, GPT-6 Luna (October
29) achieves scores of 46.19%.

8.1.2.2    SEC-Bench Pro

SEC-Bench Pro evaluates model ability to discover vulnerabilities in large JavaScript engines,
including V8 and SpiderMonkey. GPT-6 Luna (October 29) achieves scores of 51.75%, compared
with 85.4% for GPT-6 Astra.
